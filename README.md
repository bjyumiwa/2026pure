# WAIE Speech Practice

GitHub Pages 用の静的Webアプリです。

## ファイル構成

- index.html
- slides/slide-01.png から slide-26.png
- .nojekyll

## 使い方

1. GitHubに新しいリポジトリを作ります。
2. このフォルダ内のファイルをそのままアップロードします。
3. Settings > Pages で、Deploy from a branch を選びます。
4. Branch は main、Folder は /root を選びます。
5. 表示されたURLを開きます。

音が出ない時は、まず「音声テスト」を押してください。
Chrome または Edge が比較的安定します。
