# WAIE Speech Practice Compact

PCのChrome / Edgeでの発表練習用です。

- スライド画像・English narration・日本語メモを1枚のカードとして管理します。
- ↑↓でスライドを移動すると、英語と日本語の台本も一緒に移動します。
- 英語や日本語を編集すると、そのブラウザの localStorage に自動保存されます。
- GitHub上の index.html が自動更新されるわけではないので、大事な修正は「書出」で保存してください。
- Slack内ブラウザでは音声が出ないことがあります。PCのChrome / Edgeで開いてください。

差し替え方法：slides フォルダの画像を同じファイル名で上書きしてください。
