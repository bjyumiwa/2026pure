# WAIE Speech Practice App

This folder is a static speech-practice app for GitHub Pages or local use.

## Files

- `index.html`: main app
- `slides/`: slide images exported from the uploaded PDF
- `.nojekyll`: prevents GitHub Pages processing problems

## How to use locally

Open `index.html` with Chrome or Edge.
Tap the voice test button first.

## How to use on GitHub Pages

Upload `index.html`, `slides/`, and `.nojekyll` to the root of the repository.
Then enable GitHub Pages from Settings > Pages.

## Privacy note

If this is published on GitHub Pages, anyone with the URL may be able to view it.
Do not include personal information, school names, student names, API keys, consent forms, or unpublished sensitive data.
