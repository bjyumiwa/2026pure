WAIE発表練習アプリ v3 安定版

1. ZIPを解凍します。
2. index.html を開きます。
3. English narration または日本語メモを編集すると、自動保存されます。
4. 保存が心配な場合は、左の「書出」を押して JSON バックアップを保存してください。
5. 次回、内容が戻らない場合は「読込」から JSON を読み込んでください。

重要
- 前版の「保存接続」はブラウザ環境によってエラーが出やすいため削除しました。
- 自動保存はブラウザ内保存＋予備保存です。同じ index.html / 同じURL から開くと復元されます。
- ZIPを開いたままではなく、必ず解凍してから使ってください。

日本語音声入力
- PC版ChromeまたはEdgeで動きやすいです。
- ブラウザが音声入力を許可していない場合は動きません。

英訳
- 翻訳API URLを設定している場合は、日本語メモを英訳してEnglish欄に入れます。
- URL未設定の場合は、ChatGPTに貼るための英訳プロンプトをコピーします。
- 生徒名や個人情報は入力しないでください。
